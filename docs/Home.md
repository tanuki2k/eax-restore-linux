# EAX Restore for Linux

These pages cover [eax-restore-linux](https://github.com/tanuki2k/eax-restore-linux), a script that restores EAX and DirectSound3D audio in classic Windows games on Linux, using DSOAL and OpenAL Soft. To install it, start with the [README](https://github.com/tanuki2k/eax-restore-linux#readme).
